# Circlet

Crossword anagram wheel. Type letters, drag them around a circle, fill crossword squares, and optionally show dictionary answers.

Live site: https://gronowmj.github.io/circlet/

This repository is only the static build. The word list is bundled in the page (about 168,551 words, 2–15 letters), so the main script is large.

To run from the app source locally:

```
npm install
npm run dev
```

The dev server listens on port 8080.
